What every row must carry

name
Which function ran.
duration
How long it took, in milliseconds.
nesting
Which function called it. check_inventory is indented under validate_cart because validate_cart called it.
input
The arguments the function received.
output
The value the function returned.
status
Whether it finished normally or raised an exception.
